# Aurum: Economy — мод для Fabric 1.21.1

Полноценная экономика для Minecraft: **свои деньги**, **крафты**, **анимации** и жители,
которые **принимают монеты вместо изумрудов**.

| Что              | Версия                       |
|------------------|------------------------------|
| Minecraft        | 1.21.1                       |
| Fabric Loader    | ≥ 0.16.0                     |
| Fabric API       | 0.116.x (для 1.21.1)         |
| Java             | 21                           |

## Валюта (1 AU = 1 медная монета)

| Предмет          | Номинал | Крафт                                   |
|------------------|---------|-----------------------------------------|
| Медная монета    | 1 AU    | —                                       |
| Серебряная монета| 9 AU    | 9 медных монет (3×3) или 1 золотая → 9  |
| Золотая монета   | 81 AU   | 9 серебряных (3×3)                      |
| Банкнота         | 729 AU  | 9 золотых (3×3)                         |

Любую монету можно разменять обратно: 1 банкнота → 9 золотых, 1 золотая → 9 серебряных, 1 серебряная → 9 медных.

## Откуда берутся деньги

* **Монстры**, убитые игроком, роняют монеты (рейдеры — серебро, боссы — золото и банкноты).
* **Монетный двор** — ПКМ слитком: медь → 3 мед., железо/изумруд → 1 сер., золото → 1 зол., алмаз → 2 зол., незерит → 2 банкноты. `Shift` — вся стопка.
* **Продажа жителям** — всё, что раньше оплачивалось изумрудами, теперь оплачивается монетами.

## Жители

* Любая сделка с изумрудом автоматически пересчитывается: **1 изумруд = 1 серебряная монета**.
  Дорогие сделки (от 18 изумрудов) выставляются в золотых монетах.
* Работает для жителей, странствующего торговца и **уже существующих миров** (замена происходит при открытии торговли).
* Новая профессия **Банкир** (рабочее место — *Банковская стойка*): меняет изумруды на монеты, продаёт кошельки, часы, алмазы, тотемы, незерит за золото и банкноты.

## Кошелёк

* `ПКМ` — убрать все монеты из инвентаря в кошелёк.
* `Shift + ПКМ` — достать всё наличными (оптимальными номиналами).
* Баланс хранится в data-компоненте `aurum:balance`; непустой кошелёк переливается.

## Анимации

* **Монеты в инвентаре вращаются** (анимированные текстуры), банкнота переливается голограммой.
* **Фонтан монет** (собственная частица `aurum:coin` с 8 кадрами вращения) — при сделке с жителем, чеканке, дропе, работе с кошельком.
* **Анимированный HUD**: баланс «накручивается», панель пульсирует, всплывают `+N` / `-N`. Клавиша `B` закрепляет панель.
* **Витрина монет** — предмет парит, покачивается и вращается (BlockEntityRenderer).
* ПКМ по монете — подбросить её: «Орёл!» / «Решка!».

## Сборка

```bash
./gradlew build
# готовый мод: build/libs/aurum-economy-1.0.0.jar
```

Для запуска клиента из IDE: `./gradlew runClient`, сервера: `./gradlew runServer`.

## Структура

```
src/main/java/dev/aurum/economy
├── AurumMod.java            точка входа
├── currency/Currency.java   номиналы, баланс, разложение суммы, эффекты
├── economy/VillagerEconomy  замена изумрудов монетами
├── mixin/                   MerchantEntityMixin + TradeOfferAccessor
├── item/                    CoinItem, WalletItem
├── block/                   Mint, TellerDesk, CoinPedestal (+BlockEntity)
├── registry/                регистрация (предметы, блоки, профессия, частицы…)
└── event/CoinDrops.java     дроп монет с мобов
src/client/java/.../client   HUD, частица-монета, рендер витрины
tools/generate-assets.mjs    генератор текстур, моделей, рецептов, lang
```

Все текстуры нарисованы программно: `node tools/generate-assets.mjs` перегенерирует ассеты.
